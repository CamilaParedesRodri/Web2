Descripción del Proyecto
El sitio web está concebido como un espacio informativo diseñado para compartir recursos, contenidos y detalles sobre distintas asignaturas universitarias.   

🏛️ Secciones Incluidas
Encabezado / Banner: Título principal "Portal Académico Universitario" y lema "Aprendizaje, Innovación y Tecnología".   
Barra de Navegación: Enlaces principales a las secciones de Inicio, Cursos, Noticias y Contacto.   
Sección Principal (Bienvenida): Mensaje introductorio acompañado de imágenes ilustrativas del campus universitario.   

🛠️ Tecnologías Utilizadas
HTML5: Estructuración semántica del contenido (encabezados, listas de navegación, secciones e imágenes).
CSS3: Estilizado visual, manejo de paleta de colores, tipografías y maquetación del diseño.
